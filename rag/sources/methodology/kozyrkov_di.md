# Decision intelligence: decision-first framing

NOTE: this is a narrative/explanatory source (former Google Chief Decision
Scientist), not a methods authority. Use for explanation phrasing only; it
never justifies a decision.

## Decision-first, not data-first

Cassie Kozyrkov describes decision intelligence as the discipline of turning
information into better action, and frames it as decision-first rather than
data-first: a decision system is measured by whether a better decision is
made, not by model metrics alone.

## Human judgment sits on the loop

The framing brings together applied data science, social science and
managerial science while keeping a responsible human decision-maker on the
loop. This matches how this agent is built: the deterministic model informs,
but humans approve material actions.

## Application in this project

Use for wording such as "the model informs action; the decision is still
gated by humans and explicit criteria." See decision_intelligence.md for the
fuller DI stance this project implements.
